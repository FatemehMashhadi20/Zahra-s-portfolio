
# Artist Portfolio Website

A sleek and modern portfolio website developed to showcase an artist's traditional drawings. The website is built using **Next.js**, **TypeScript**, and **Tailwind CSS**, ensuring a performance-optimized, responsive, and visually appealing user experience. The site features smooth dynamic image rendering, fast navigation, and an intuitive design that highlights the artist’s work.

## ✨ Live Demo

You can view the live demo of the project at:  
[zahra-s-portfolio.vercel.app](https://zahra-s-portfolio.vercel.app/)

## 🚀 Technologies Used

- **Next.js**: For building the frontend with a focus on performance, SEO, and server-side rendering.
- **TypeScript**: For enhanced code reliability and scalability.
- **Tailwind CSS**: For responsive design and utility-first styling.
- **React**: As the JavaScript library for building interactive UIs.

## 💻 Features

- **Dynamic Image Rendering**: Smooth transition and rendering of images as users browse through the portfolio.
- **Responsive Design**: Fully responsive layout optimized for desktops, tablets, and mobile devices.
- **Optimized Performance**: Fast loading times and seamless navigation for an intuitive user experience.
- **Intuitive Navigation**: Easy-to-use navigation for quickly exploring the artist’s work.

## 🛠️ Installation and Setup

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/artist-portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd artist-portfolio
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open the app in your browser at `http://localhost:3000`.

## 🎨 Development

- **Component-Based Architecture**: The project was developed with a component-based architecture using React and Next.js, promoting reusability and maintainability.
- **Tailwind CSS Customization**: Custom configurations were made to fit the specific design needs, making the site visually unique.

## 📈 Performance Optimizations

- Image loading is optimized for faster performance using Next.js's built-in image component.
- Static site generation (SSG) is utilized for improved page load times and SEO benefits.

## 📂 Folder Structure

- `components/`: Contains reusable components such as the header, footer, and portfolio gallery.
- `pages/`: Next.js pages, including the homepage and individual portfolio pieces.
- `styles/`: Tailwind CSS configuration and global styles.
